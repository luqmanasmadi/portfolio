How I work with AI coding tools

  • Spec first. I write the goal, scope and acceptance checks before any code is generated.
  • One chat per task. Small, focused sessions keep context clean and output predictable.
  • Switch models when stuck. If one model loops, I try another with a tighter prompt.
  • Review and test. I read what was generated, run it, and report bugs back with exact steps.
  • Ship in small increments. Weekly iterations, each one working end to end.
